# Zepo Design System

## Para humanos

Solo di: **"haz la pantalla de [X]"** o **"rediseña [X]"**.

Claude ya sabe el flujo (ver `../CLAUDE.md`).

## Archivos

| Archivo | Para qué |
|---|---|
| `DESIGN.md` | Principios y reglas de marca |
| `tokens.json` | Colores, fuentes, spacing, motion (W3C DTCG) |
| `components.md` | Catálogo de 18 componentes con código |
| `patterns.md` | 11 flujos canónicos multi-pantalla |
| `examples/` | Código JSX de Claude Design (referencia visual) |

## Política de cambios

- Agregar tokens/componentes nuevos: libre.
- Cambiar valor de un token existente: breaking, avisa antes.
- Cambiar patterns: impacta múltiples pantallas, discútelo.
